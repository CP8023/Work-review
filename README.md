# 工作复盘

一个只给自己用的本地「每日工作复盘」应用。原生 HTML / CSS / JavaScript，零依赖、零构建、离线可用，可安装为 PWA。

没有账号、没有服务器、没有埋点。所有记录只保存在你自己的浏览器里。

---

## 快速开始

### 方式一：双击 `启动.bat`（推荐）

需要电脑上装有 **Node.js** 或 **Python**（脚本会自动选择）。

- 会自动打开 `http://localhost:5173`
- 如果端口被占用，会自动顺延到 5174、5175…
- 关闭窗口或按 `Ctrl + C` 停止服务

也可以手动启动：

```bash
node server.js
# 或指定端口
PORT=5200 node server.js
```

### 方式二：直接打开 `index.html`

双击即可使用，数据同样保存在本机。

但 `file://` 协议下浏览器不会注册 Service Worker，因此**不能安装成应用、也没有离线缓存**。日常使用建议用启动脚本。

### 手机安装（推荐：装到鸿蒙 / 安卓 / iPhone）

应用是纯静态的，没有后端，所以放到任意 **HTTPS 静态托管**上，手机打开后
「添加到主屏幕」就是一个独立图标的应用，**电脑不用开机，离线也能用**，
记录仍然只写在手机本地。详细步骤见 **[手机安装.md](./手机安装.md)**：

1. 双击 `打包部署.bat` → 生成 `dist\` 和 `deploy.zip`
2. 把 `dist\` 里的文件上传到 GitHub Pages / Cloudflare Pages / 国内云静态托管
3. 手机浏览器打开该 HTTPS 网址 → 菜单 →「添加到主屏幕」

### 手机临时访问（局域网，电脑需开机）

1. 电脑和手机连接同一个 Wi-Fi
2. 在电脑上运行 `启动.bat`
3. 手机浏览器打开 `http://电脑的局域网IP:5173`

> 注意：局域网 HTTP 下可以正常使用，但浏览器要求 **HTTPS 或 localhost** 才能注册 Service Worker、离线缓存和安装成应用。想让手机独立使用，按上面的「手机安装」走 HTTPS 托管，数据仍然只存在手机本地。

## 功能

### 今日

- **速记 / 收集箱**：随手记一条工作事件、想法、问题、经验或待复盘，先收起来，稍后整理成行动或删除；支持浏览器语音输入
- **日复盘**：日期切换、心情、精力、项目、一句话总结、四段正文（完成 / 收获 / 问题 / 反思）、明日计划、标签
- **提醒条**：今天还没写复盘、或有行动逾期时，页面顶部会出现一句提醒（当天可关闭）
- **自动保存**：输入后约 0.6 秒写入本地，切换页面前也会强制保存
- **待办行动**：今天页面直接看到并勾选所有待办行动
- **新建复盘**：周复盘、月复盘、项目复盘、事件复盘、自由复盘；也可一键生成「本周 / 本月事实草稿」

### 时间线

- 月历视图，有日志的日期会标记
- 全文搜索
- 按类型（日志 / 复盘）、标签、项目筛选（项目筛选对日志同样生效）
- 日志与模板复盘按日期统一展示，日志会显示所属项目
- **随机回顾**：随机翻一篇旧记录

### 项目

- 日志、复盘、行动上填过的项目名会自动聚合成项目卡片
- 单个项目里可以看到：日志天数、复盘篇数、行动 / 待办数量与最近记录
- 项目内的行动可直接勾选完成、也能就地添加新行动
- 项目可重命名（会同步改掉日志、复盘、行动上的项目名），也可一键在时间线里按项目查看
- 从项目页新建的复盘会自动带上该项目

### 行动

- 截止日期、项目、来源（从哪个复盘来的）
- 自动分为：逾期 / 今天 / 接下来 / 没有日期
- 待办 / 已完成 / 全部
- 完成率、本月完成数

### 洞察

- 连续记录天数、复盘总数、行动完成率、累计字数
- 近 12 周记录热力图
- 近 14 天心情曲线
- 复盘类型分布、常用标签、项目分布（点击可跳到项目页）
- 本月数据
- **一键汇总**：生成本周 / 本月复盘草稿，事实（记录、字数、心情、行动完成情况）自动填好，只留思考部分给你

### 设置

- 浅色 / 深色 / 跟随系统
- **自动备份到网盘文件夹**：选择网盘同步目录里的一个 .json 文件，保存后自动覆盖写入（Chrome / Edge 等支持 File System Access 的浏览器）
- 分享备份（手机系统分享面板）、复制备份到剪贴板
- 导出 JSON 备份、Markdown、行动项 CSV
- 导入 JSON（合并，相同日期或 ID 以备份为准）
- 存储用量、安装应用、清空所有数据

## 数据与备份

- 存储位置：浏览器 `localStorage`，键名 `work-review-v1`
- 数据结构版本：`2`
- 删除浏览器站点数据、无痕模式关闭、重装系统都会导致数据丢失
- **建议每周导出一次 JSON**，存到网盘或本地文件夹
- **自动备份（本地 + 网盘）**：
  - 在设置页选择**网盘同步文件夹**（坚果云 / OneDrive / 百度网盘等的本地同步目录）里的一个 `.json` 文件，开启自动备份后每次保存会自动覆盖写入该文件 —— 等于免费上云，无需注册任何服务
  - 文件句柄保存在浏览器 IndexedDB（`work-review-backup`），换浏览器 / 清缓存后需重新选择一次
  - 不支持该 API 的浏览器（Safari / Firefox / 手机浏览器）可用「分享备份」（Web Share）或「复制备份」，或定期手动导出 JSON
  - 备份超过 14 天未更新时，「今日」提醒条和设置页会提示
- 导入时：
  - 日复盘按日期合并，同一天以备份为准
  - 模板复盘、行动、速记按 ID 合并
  - 不会清掉现有数据
- Markdown 适合阅读、打印、迁移到其他笔记工具
- CSV 只包含行动项，方便在表格里跟进
- JSON 备份包含：日复盘、模板复盘、收集箱、行动项、主题设置

### 存储容量

`localStorage` 通常只有 5 MB 左右。纯文本足够写很多年，但不要存大图片或附件（本版也不支持）。

## 已知限制 / 后续可做

- **跨设备同步**：目前没有服务器，用 JSON 备份在设备间手动迁移；或用「自动备份到网盘文件夹」让多设备通过网盘共享一份备份（换设备后在设置页导入即可）。真正的双向实时同步需要自建 WebDAV / 对象存储或托管服务。
- **附件 / 拍照**：受 `localStorage` 容量限制，本版不存图片。
- **语音输入**：使用浏览器 Web Speech API（Chrome / Edge 可用，通常需要联网），不支持时按钮会被隐藏。
- **提醒推送**：没有系统通知（浏览器要求 HTTPS + 推送订阅），目前是打开「今日」时的页内提醒条。
- **密码锁 / 生物识别**：未实现。
- **经验卡片、AI 摘要**：留待后续。
- **项目**：轻量聚合模块——日志、复盘、行动共用一个自由文本的项目名，可筛选、可重命名，但没有任务分解、成员、进度等完整项目管理能力。

## 更新缓存

如果修改了 `css/`、`js/` 等静态文件，请把 `sw.js` 顶部的 `VERSION` 改成一个新值，例如：

```js
const VERSION = 'v1.2.0';
```

然后刷新两次页面，旧缓存会被替换。
